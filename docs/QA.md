# تحقق الإصدار — 2026-09-05

## تم بنجاح

- `npm test`: أربع مجموعات اختبارات حقيقية تشمل تحويل العربية وUnicode إلى رابط واسترجاعها، قراءة QR من PNG، رسالة بطول 400 حرف، رفض الروابط التالفة ومصادر يوتيوب غير المسموحة.
- اختبار API كامل: دخول المالك، إضافة محلين، منع حساب محل من لوحة المالك، عزل مكتباتهما وهوية كل محل، منع التعديل العابر للمحلات، حصة الكروت ومنع تجاوزها، تعديل وإيقاف وإعادة فتح نفس الرابط، انتهاء الاشتراك مع استمرار كروت العملاء، تسجيل الخروج، تغيير كلمة المرور وإبطال الجلسات الأخرى، رفض Origin خارجي.
- بناء العرض وبناء التجارية عبر Vite دون أخطاء.
- تشغيل التطبيق التجاري في Node محليًا، وفحص لوحة المالك وإضافة محل والدخول بحسابه وتوليد كرت وفتح رابط المستلم.
- تحميل PNG من واجهة التطبيق، فحصه بصريًا، والتحقق من أبعاده 1400×1000، وفك QR منه باستخدام jsQR: الرابط التجاري يطابق الكرت.
- اختبار إنشاء مجموعة بأسماء مكررة من الواجهة: ثلاثة أسطر أنتجت كرتين مستقلين، كما هو متوقع.
- فحص شاشة الكمبيوتر داخل إطار بعرض 1440، والجوال داخل إطار بعرض 390. لا تجاوز أفقي عند 390 (scrollWidth=clientWidth=390). استُخدم الإطار لأن تغيير مقاس متصفح الأداة لم يُطبق على السطح المحلي.
- تجربة تحويل رابط النسخة القديمة `?l=` إلى legacy.html وظهور رسالة الاختبار القديمة.
- بناء Docker image وتشغيلها بـ Node 24، HTTP 200 من `/api/config`، جلسة إنتاج تحمل Secure وHttpOnly وSameSite=Strict، وترويسة CSP.
- نسخة احتياطية SQLite من قاعدة اختبار مع WAL؛ فحص النسخة أعاد `integrity_check: ok` وكرت الاختبار موجود.
- `npm audit --omit=dev`: صفر ثغرات معلنة وقت الفحص.

## حدود التحقق

- لم تُنفّذ عملية طباعة ورقية أو مسح بكاميرا جهاز فعلي. قراءة الصورة تمت بمكتبة QR مستقلة.
- لم يُختبر كل موديل هاتف أو نظام تشغيل. فُحصت واجهة المتصفح والتجاوب وملف التصدير الفعلي.
- لم تُفعّل استضافة تجارية خارجية أو شهادة نطاق حقيقي. ملفات Docker Compose/Caddy مجهّزة؛ Docker نفسه بُني وشُغّل، بينما إضافة Compose غير متاحة في البيئة الحالية.
- لم يُجرَ اختبار ضغط إنتاجي أو تدقيق أمني خارجي. SQLite هنا لنشر واحد على قرص دائم.
- لا بوابة دفع مفعلة، ولا حسابات عملاء حقيقية أُنشئت أو بيانات محلات أُرسلت. حسابات الاختبار محلية فقط.

نتيجة النشر العام لنسخة العرض تُوثّق في تسليم المحادثة بعد فحص رابط GitHub Pages.
