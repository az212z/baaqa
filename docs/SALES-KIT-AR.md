# حقيبة عرض باقة على محلات الهدايا

## عرض مختصر

باقة تضيف رسالة رقمية شخصية إلى كل هدية يبيعها المحل. الموظف يختار تصميمًا، يكتب اسم المستلم وكلمات المرسل، ويطبع باركودًا. المستلم يمسحه فتفتح له رسالة داخل ظرف رقمي بهوية المحل.

## تجربة العرض خلال دقيقتين

1. افتح نسخة العرض واختر مناسبة وتصميمًا.
2. استخدم اسم صاحب المحل كمستلم، واكتب رسالة قصيرة.
3. افتح معاينة المستلم ودعه يفتح الظرف.
4. نزّل البطاقة وامسح باركودها بكاميرا هاتف آخر.
5. اشرح أن النسخة التجارية تمنحه حسابه ومكتبته وروابط قابلة للتعديل، وتبدأ بعد تفعيل اشتراكه.

## ما تبيعه

اشتراك استخدام للمحل، لا بيع المستودع العام على أنه كود حصري. يشمل مساحة المحل، عدد كروت متفقًا عليه، تخصيص الاسم، تحديث المحتوى دون إعادة الطباعة، ومساعدة أولية في التشغيل. الأمان والحصص تُفرض في الخادم حتى لو شاهد شخص كود الواجهة.

اختر سعرًا بحسب تكاليف الاستضافة والدعم وعدد الكروت وحجم العميل. لا تتضمن هذه الحقيبة وعد أرباح أو سعر سوق موثّق. يمكن تنظيم عروضك إلى تجربة قصيرة، اشتراك محل، وباقة حملات كبيرة؛ أنشئها يدويًا بالمدة والحصة المناسبتين.

## نص تقديم جاهز (غير مرسل)

مرحبًا، عندي «باقة» لمحلات الورد والهدايا: تضيفون مع كل طلب كرتًا بباركود يفتح رسالة شخصية بتصميم أنيق واسم محلكم. إنشاء الكرت بسيط، وتقدرون تطبعونه أو تشاركونه، وحتى تعدّلون الرسالة بعد الطباعة. أقدر أعرض عليكم التجربة بكرت باسم محلكم.

## تسليم كل محل

دوّن اسم المحل، اسم المستخدم، تاريخ البداية والنهاية، إجمالي حصة الكروت، والسعر وشروط التجديد المتفق عليها. أكّد الدفع خارج النظام ثم فعّل الحساب. اشرح تغيير كلمة المرور والطباعة والنسخ الاحتياطي. قدّم قناة الدعم التي تديرها فعلًا.

## الحدود التي يجب شرحها

- يلزم الإنترنت لفتح الكرت أول مرة. لا تعد بعمله بلا اتصال.
- كل من يملك رابط الهدية يستطيع فتحها؛ لا تُستخدم للمعلومات الحساسة.
- استمرار الكروت مرتبط باستمرار النطاق والخادم والنسخ الاحتياطية.
- انتهاء اشتراك المحل لا يوقف كروت عملائه الحالية.
- لا توجد حاليًا فاتورة ضريبية تلقائية، تحصيل إلكتروني أو إحصاءات مشاهدة.
- لا تستخدم نسخة GitHub المفتوحة كحساب اشتراك مدفوع؛ اعرضها كتجربة فقط.
