# مراجعة باقة

المصدر: https://az212z.github.io/baaqa/، فُحص في 2026-09-05.

الموقع الأصلي: ملف HTML واحد، لوحة عربية لمحلات الورد، ألوان نبيذية وذهبية، خطوط Amiri/Tajawal، خيارات كثيرة ظاهرة دفعة واحدة. يدعم رسائل وباركود وروابط قديمة مضغوطة وتجارب محلية محدودة. هذه التجارب لا تشكل نظام تراخيص خادميًا.

التوجه: إعادة بناء طلبها المالك، مع إبقاء الاسم وفكرة كرت الهدية والروابط القديمة. واجهة منتج خفيفة، وردي هادئ ومساحات نظيفة ومعاينة ورقية. للمقدمة والهوية فقط طُبقت مهارة design-taste-frontend؛ نماذج المنتج تستخدم عناصر HTML أصلية متاحة بلوحة المفاتيح.

المعايير: DESIGN_VARIANCE=6، MOTION_INTENSITY=3، VISUAL_DENSITY=4. خطوط محلية، أيقونات Phosphor، تأثير دخول قصير مع احترام تفضيل تقليل الحركة. ستة طوابع مرئية، تسع مناسبات، خطوات واضحة دون فقد البيانات عند التنقل.

التوافق: احتفظنا بالنسخة السابقة في legacy.html. يحيل المسار الرئيسي روابط c/l/t وd/c القديمة إلى قارئها الأصلي. الروابط الجديدة في نسخة العرض مستقلة عن التخزين المحلي. التجارية تستخدم معرّفًا عشوائيًا وبيانات خادمية.
