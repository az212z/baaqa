# باقة — نظام كروت الباركود للمناسبات

نظام ويب كامل لمحلات الهدايا والورد لإنشاء كروت رقمية مع باركود QR. كل باركود يفتح صفحة مصممة بموشن حي مخصص للمناسبة (عيد ميلاد، زواج، حب، تخرج، مولود، شكر، عيد الأم، سلامات، عيد).

## المميزات

- **لوحة المحل**: تصميم كرت بالمناسبة، اسم المستلم/المرسل، الرسالة، اسم المحل
- **معاينة مباشرة** للكرت قبل توليد الباركود
- **صفحة تصدير للطباعة**: ٣ قوالب (بطاقة كاملة، ملصق دائري، QR فقط)
- **تحميل SVG / PNG** أو طباعة مباشرة
- **صفحة استلام سينمائية**: مغلف مختوم يفتح، رسالة تظهر بحبر فاخر، وموشن مخصص لكل مناسبة
- **٩ مناسبات** بألوان وموشن مختلف لكل واحدة
- **يعمل بدون سيرفر** — كل شي داخل ملف HTML واحد
- **عربي RTL كامل** مع خطوط Amiri و Tajawal

## النشر

هذا المستودع مُعدّ لـ **GitHub Pages**. فعّله من:

1. `Settings` → `Pages` (يسار)
2. تحت **Source**: اختر **Branch: main** و **/(root)**
3. اضغط **Save**
4. انتظر دقيقة، رابطك يصير: `https://az212z.github.io/baaqa/`

## الاستخدام

- افتح الرابط من أي جهاز
- اختر المناسبة، اكتب رسالتك، اضغط «توليد الباركود»
- اطبع الباركود على الكرت أو ألصقه على الغلاف
- العميل يمسحه بكاميرا جواله → تنفتح صفحة الرسالة مع الموشن

## البنية

- **`index.html`** — الملف الوحيد. يحتوي كل الكود (HTML/CSS/JS + مولد QR كامل).
- لا يوجد `node_modules` ولا `build step`.
- الخطوط تُحمّل من Google Fonts.
