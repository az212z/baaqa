# باقة | استوديو الهدايا الرقمية للمحلات

منتج عربي لإنشاء كروت هدايا بباركود، مع نسخة عرض ثابتة ونسخة تجارية قابلة للاستضافة.

## الروابط

- العرض: https://az212z.github.io/baaqa/
- [دليل التشغيل التجاري](docs/OPERATIONS-AR.md)
- [حقيبة العرض والبيع](docs/SALES-KIT-AR.md)
- [المراجعة والاختبارات](docs/QA.md)

## تشغيل سريع

Node.js 24+. `npm ci` ثم `npm run dev`.

`npm test` للاختبارات، `npm run build` لبناء العرض، `npm run build:commercial` لبناء النسخة التي تتطلب الحسابات. النسخة التجارية تحتاج ADMIN_PASSWORD و`npm start`، أو Docker Compose كما في الدليل.

## الميزات

- 9 مناسبات، 6 طوابع، خطان عربيان محليان، ظرف تفاعلي، نغمة اختيارية وإهداء يوتيوب اختياري.
- معاينة مباشرة، QR فعلي، بطاقة PNG بدقة 1400×1000 ورمز SVG وورقة طباعة جماعية.
- مكتبة وبحث ونسخ احتياطي واستيراد، حتى 30 مستلمًا في مجموعة.
- تجاري: حساب مالك، حساب محل، انتهاء وحصة، كلمات مرور مشتقة، جلسات آمنة، عزل بيانات.
- تجاري: رابط قصير ومعرف عشوائي، تعديل الرسالة بنفس الباركود، إيقاف وإعادة تفعيل.

## بنية المشروع

`frontend/src/` الواجهة وموديل الكروت. `server/` الخادم وSQLite. `tests/` اختبارات QR ودورة الاشتراك. `frontend/public/legacy.html` قارئ الروابط السابقة. الملفات في الجذر و`app-assets/` هي نسخة GitHub Pages الناتجة؛ حرر المصدر ثم أعد البناء.

لتحديث العرض: `npm run build` ثم `node scripts/publish-static.mjs` ثم commit/push. لا تنشر مخرجات build:commercial على GitHub Pages.

## الحالة التجارية

التحصيل والتفعيل يدويان. لا توجد بوابة دفع أو تحليلات مسح وهمية. الاستضافة التجارية والنطاق والأسرار ونسخ البيانات مسؤوليات تشغيل فعلية موضحة في الدليل.

جميع حقوق الكود المملوك للمشروع محفوظة لصاحب المشروع. الاعتماديات والخطوط والصورة تحت تراخيص أصحابها؛ راجع THIRD-PARTY.md.
